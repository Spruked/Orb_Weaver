Excluded from this map: .git/, node_modules/, frontend/build/, Python caches,
and generated vault payload contents.

Vault topology invariant:
  • Six physical vault-like directory systems exist in this repository.
  • repository-root vault_system/ is the sole authoritative runtime Vault.
  • Root Orb_Vault_System/ is an active code provider only; the main runtime
    injects its data paths beneath the canonical Vault.
  • A prior manufacturing dual-store defect was repaired at package assembly:
    new packages carry only runtime/vault_system; SKG receives explicit paths
    below it and fails closed without that exact canonical root.
  • The builder excludes vendor TPC API/results/vaults persistence surfaces;
    source/vendor structures remain in the repository pending separate audit.
  • frontend/vault_system/ still requires activation/read/write proof before
    migration, inert treatment, or removal.
  • substrate/ is compatibility-only, not a seventh Vault.
  • vault_system/clients/<domain>/.../orb_vault_skg/ directories are legal
    subordinate namespaces; they must not establish an independent root.
