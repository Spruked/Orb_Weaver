Runtime boundaries:
  • frontend/src/App.tsx owns the public/authenticated route boundary.
  • frontend/public/sitemap.xml describes indexable public URLs; it excludes workspace/admin routes.
  • backend/main.py owns the HTTP API and WebSocket entry points used by the frontend.
  • repository-root vault_system/ is the sole authoritative runtime Vault.
  • Generated payloads, caches, build output, node_modules, Python caches, and .git/ are excluded from this map.
